# Sample Residue v0.2

## Rule

Sample Residue is visible content tied to one work or a small subset rather than a reusable decision. Exact objects, poses, palettes, locations, seams, and arrangements must not enter general reconstruction automatically. Only the underlying visual function may transfer, and only when the new source contains an equivalent need.

## Residue tests

Before transferring any visible feature, ask:

1. Does it recur as a decision across works, or only as an object or motif?
2. Would the visual method remain recognizable if this exact feature disappeared?
3. Does the new source contain an equivalent structural need?
4. Can the function be expressed without reproducing the reference arrangement?
5. Does the proposed feature exist in the new source, or is it being justified only as a shortcut for `identity_core`, `gesture_pose`, `scene_idea`, or mood?

If the answers indicate object-specific recurrence or no source need, the feature remains residue. Visible sheet seams are residue by default and become a variable only when the intended physical support genuinely requires assembled sheets.

The preservation core in `00-intent-contract.md` does not authorize invention. A source-absent chair, road, flower, garment, sun, ring, seam, or other corpus motif remains residue even when it appears to support the desired emotion. Preserve or transform source-present cues; transfer only abstract function.
