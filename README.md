# Expressive Watercolor Reconstruction

**把一张真实照片重构为透明水彩画面：由色面、光感和空间关系组织整体，只在表情、形体转折与关键连接处留下有节奏的线条。**

<sub>一个面向 Codex 内置 Imagegen 的单照片创作 Skill。先判断什么必须保留，再决定什么可以重组、合并或不画。</sub>

## 30 秒看懂

| 你提供什么 | Skill 会重点处理什么 |
| --- | --- |
| 一张人物照片 | 保留辨识身份、姿态与必要的目光或嘴部神态；让局部线条服从整体水彩色面。 |
| 一张街景或建筑照片 | 保留场所关系、关键连接和可信接地；将重复窗格、栏杆等组织成更大的形体。 |
| 一张风景照片 | 让海、天空、山坡等连续色面组织空间；把树叶、草、波纹等重复细节压到必要位置。 |
| 一张物体或事件照片 | 保留形体连接、接触或用途关系，省略不支撑辨识的零件和背景库存。 |
| “只给我提示词” | 输出最终四段 Imagegen 提示词，不生成图片。 |

核心流程：

```text
一张原照片
→ 找到辨识核心与场景关系
→ 组织 3–5 个主要色面或形体
→ 分配重点、次要和安静区域
→ 编译提示词并用内置 Imagegen 生成
→ 查看真实画面，记录保住了什么、哪里仍失败
```

这里的“重构”允许改写空间、比例、构图、颜色和局部形体，但不能丢掉照片中真正支撑主体与场景的关系。

## 它怎样处理一张照片

| 容易出现的结果 | 本 Skill 的目标判断 |
| --- | --- |
| 只把照片盖上一层水彩纹理，物体和透视逐项照搬。 | 先选主要形体与空间关系，再决定局部如何用透明水彩完成。 |
| 每扇窗、每片叶、每道波纹都画出来。 | 保留少数能说明身份、动作或空间的节奏组，其余合并为连续色面。 |
| 为了“简洁”把表情、接触点或旧楼特征删掉。 | 让有用的局部线条保留轻重、断续和方向变化，不按笔数机械删减。 |
| 整张画都加纸纹、描边或相同笔触。 | 大面积透明色洗主导整体，较浓的颜料和干笔中断只在选定区域出现。 |

这些是生成与检查时采用的判断标准，不是对每张照片效果的保证。真实图像仍需逐张检查。

## 快速开始

### 安装

需要能够使用内置 Imagegen 的 Codex 环境；无需为这个 Skill 单独配置 API key。首次安装时运行：

```bash
git clone https://github.com/mumuysd/expressive-watercolor-reconstruction.git "$HOME/.codex/skills/expressive-watercolor-reconstruction"
```

如果目标目录已经存在，`git clone` 会停止，不会覆盖已安装文件。安装后在下一轮对话使用 Skill。

### 直接生成

上传一张真实照片，然后说：

```text
请用 expressive-watercolor-reconstruction 重构这张照片。保留主体辨识核心和动作关系，让透明水彩色面与空间重组主导画面；只在表情、形体转折和接触点保留有变化的线条。不要添加文字。
```

有必须保持的部分，请直接补在请求里。例如：“这栋旧楼的墙脚必须自然落在道路上；车辆可以省略，但不要凭空补出整排门洞。”

### 只要提示词或分析

在同一张照片后明确说“只输出最终提示词，不生成图片”，或“只分析这张照片，不生成图片”。默认模式是直接生成。

## 功能地图

| 环节 | 作用 |
| --- | --- |
| 辨识核心 | 区分主体身份、适用时的动作姿态，以及照片的场景关系。 |
| 空间与色面 | 用 3–5 个主导形体和结构性色彩替换零碎库存。 |
| 信息分区 | 指定重点线条、辅助细节、连续水彩色面，以及明确不逐件画的元素。 |
| 区域笔触 | 将轻重变化、断续、湿色沉积或干笔中断放在有作用的连接处。 |
| 实图检查 | 对照原照片检查辨识、重构、水彩材质、安静区和重复细节。 |
| 局部修订 | 仅在整体方向已被接受且恰好剩一个可局部修复的问题时，最多修订一次。 |

## 适用场景

人物、动物、街景、建筑、自然风景、物体、产品、车辆、静物和可见事件，都可以从**一张真实照片**开始。默认保持原照片的显示方向，输出不带文字。

这个 Skill 不处理截图、文档、图表或已有艺术作品的风格临摹；也不把另一张画、旧生成图或其他 Skill 的素材当成风格参考。

## 运行边界

- 每次生成周期只处理一张原照片，且它是直接生成时唯一的视觉输入。
- 照片中的精确文字、品牌、构件数量和几何形状并非默认保证；如果它们必须保持，请在请求中说明。无法同时满足精确保留与可见重构时，Skill 会先指出冲突。
- 水彩色面在整体上保持主导。重复细节铺满安静区与删减过头、损失神态或空间关系，都属于失败。
- 先检查实际生成图，再判断是否合格；多个区域有问题时不会靠连续重试掩盖。
- 本仓库不收录用户照片、研究照片、测试图或验证记录。生成时照片会按 Codex/Imagegen 当前方式处理。
